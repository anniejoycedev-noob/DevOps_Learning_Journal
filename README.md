# Introdution of DevOps
**What is DevOps?**

It's a culture that improves the delivery of the applications of the organization.

CI/CD -> Continous Integration/Continous Delivery

DevOps is to improve the-
1. Delivery
2. Automation (For the Manufacture)
3. Quality (For the Client)
4. Monitoring (for maintenance)
5. Testing

_DevOps is a process of improving the application/script/binary delivery bu ensuring that there is a proper automation, quality to maintain,  continous monitoring and continous testing in place._

**Why DevOps?**
To reduce the long process of System Development LifeCycle (SDLC). 
Ex -  An organization wants to create a product. Before DevOps was known, the Devs creates code checks it on their PC. This application needs to be checked by others too so it is sent to a central location where the other devs go through the application.The central location is mainntained by a System Administer who creates a server to host the app. And on this app a Tester tests and if the app passes it then it goes to the Build and Release Engineer. BRE then push it to the main server where the actual clients are. 

It's a long process taking 10 days to 2 months for an application to get to the client.

Hence, evolved the role DevOps.

**Software Development LifeCycle (SDLC):**
It's a process, a set of standards to Design, Develop and Test. To give an end product of High Quality.

Planning ---> Defining ---> Designing ---> Building ---> Testing ---> Deploy 

_(And back to the first step for introducing new features)_

The Pillars of SDLC - 
1. Planning
2. Defining - develops a software requirement/ specification document.
3. Designing - **HLD** High Level Deign and **LLD** Low Level Design
4. Building (dev) - Developing of products keeping the Software requirement, HLD, and LLD document in mind. 
5. Testing (QE) - The code written by the developer is tested in a server observed by Quality Assurance Engineers (QE).
6. Deploy --> Prodution --> Client

from 4 to 6 is where Automation is needed i.e. where DevOps play their role.

_DevOps Engineer works as a catalyst to fasten the process to make everything automated and improve efficiency_

What to say when the interviewer ask you whuch part of the SDLC are you interested in?<br>As a DevOps Engineer I am interested in the automation sector -> Building, Testing and Deploying.
